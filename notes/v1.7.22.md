## Conte 1.7.22 · 预发布

本版仅供预发布验收，尚不作为正式销售版本。

- 左侧目录树、文件夹表格和研究空间可直接拖动排序；普通点击、右键和键盘排序保留，同级与分组边界继续生效。
- “添加日期”和“修改日期”列默认显示、右对齐，可按升序和降序排序。
- “复制页面”可把当前 Conte 工作台或文件夹表格在新标签打开，原标签及其状态保留；不会复制笔记正文。
- 普通 Markdown 笔记可启用标题持续编号。YAML 属性和 fenced code 保持原文，标题编号可随编辑撤销。
- 显式打开缺少表格入口的旧文件夹导航页时，Conte 会补上表格代码块；既有正文和 YAML 保留，撤销与重做不更改原“修改日期”。

自动化测试 479/479 通过。独立 Obsidian 预览库已验收文件夹表格入口补齐、撤销与重做保留修改日期，以及日期表头与单元格文字右缘对齐。用户拖动实测、真实 Vault 升级、插件内更新安装、Windows 与 Zotero 目标应用验收仍待完成。
